# Web Interface

Web tabanlı Particle Studio arayüzü burada geliştirilecek.

Planlanan ekranlar:
- Görsel yükleme
- Parçacık / ASCII modu seçimi
- Siyah-beyaz / renkli çıktı seçimi
- Parçacık yoğunluğu, boyutu ve animasyon süresi ayarları
- Önizleme
- Tek HTML dosyası veya terminal çıktısı dışa aktarma

Not: Web arayüzü ile Python motoru arasındaki iletişim yöntemi (yerel API veya paketlenmiş masaüstü çalışma modu) uygulama aşamasında netleştirilecek.
